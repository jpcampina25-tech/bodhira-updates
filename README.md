# BODHIRA — Atualizações

Este repositório público é usado exclusivamente para distribuir as versões instaláveis do **BODHIRA Desktop** e os metadados necessários ao atualizador automático.

- O código-fonte e o desenvolvimento permanecem no repositório privado `bodhira-desktop`.
- As Releases deste repositório contêm os instaladores do Windows e os arquivos de atualização do Electron.
- Não envie aqui código-fonte, credenciais, tokens ou arquivos pessoais.

Para baixar o aplicativo, consulte a seção [Releases](https://github.com/jpcampina25-tech/bodhira-updates/releases).
